UndiBukti

A verifiable community draw (raffle / giveaway) for Tari Ootle. The winner is derived from a future consensus epoch hash, so the organizer cannot pick the winner after entries close — and anyone can recompute the result.

Walletless simulation of the UndiBukti Tari template — no real funds, no live network.

Two-minute demo

Free entry is the main demo path (a paid mode exists in the template and here). Accounts are names standing in for signer public keys; on-chain, entry identity is the transaction signer, so entries cannot be forged for someone else.

    Verify it yourself

    Do not trust this page. Paste any entry list (one account per line, in entry order) and the epoch hash of the draw epoch, and the winner is recomputed here, in your browser, with the template's formula:

    winner_index = u64_from_le_bytes(first 8 bytes of epoch hash) mod entry_count

    UndiBukti is an open-source (MIT) Tari template. The on-chain template and its engine tests are the source of truth; this page simulates the same rules off-chain. A parity test (docs/parity-test.mjs) checks this simulation against winner-index vectors produced by the Rust code (tests/parity_vectors.rs).
